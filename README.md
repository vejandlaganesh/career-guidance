# 🎓 Edu Carrier

> **Explore • Learn • Discover • Plan Your Future**

**Edu Carrier** is an AI-powered career guidance platform that helps students explore educational streams, discover careers, understand courses and entrance exams, assess their interests, receive personalized career recommendations, and plan their future career paths.

---

## ✨ Features

### 🎓 Career & Education

* Career Explorer with search and filters
* Explore Streams with subjects, courses, and related careers
* Detailed Career Profiles
* Course and College information
* Career Comparison

* Career Quiz

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd edu-carrier
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file and add the required API configuration:

```env
GEMINI_API_KEY=your_api_key_here
```

### 4. Start the development server

```bash
npm run dev
```

Open the URL shown in the terminal.

## 🎯 Project Goal

Edu Carrier aims to provide students with a complete career-planning ecosystem by connecting:

**Streams → Courses → Skills → Careers → Exams → Resources → Activities → Career Roadmaps**

The goal is to help students **explore their options, understand their strengths, discover suitable careers, and plan their next steps**.
