# 🎓 Edu Carrier

> **Explore • Learn • Discover • Plan Your Future**

**Edu Carrier** is an AI-powered career guidance and education platform designed to help students explore educational streams, discover careers, understand courses and examinations, assess their interests, receive personalized career recommendations, track their progress, and access continuously updated educational activities and resources.

The platform combines **career exploration, stream exploration, career assessment, personalized recommendations, exam information, preparation resources, real-time student activities, notifications, and AI-powered career guidance** into one student-friendly application.

---

# 🌟 Project Overview

Students often struggle to understand:

* Which stream should they choose?
* What careers are available after a particular stream?
* Which courses lead to a specific career?
* Which entrance exams are required?
* When are exam applications and examinations conducted?
* What skills are required for a career?
* What should they learn next?
* Which career is suitable for their interests and abilities?

**Edu Carrier** brings these areas together into one platform.

The application provides a connected journey:

```text
Explore
   ↓
Understand
   ↓
Assess
   ↓
Discover
   ↓
Compare
   ↓
Plan
   ↓
Learn
   ↓
Track
   ↓
Grow
```

# 📅 16. Exam Important Dates

Exam information should support a complete timeline rather than storing only one examination date.

Important dates can include:

```text
Application Opens
Application Deadline
Correction Window
City Intimation
Admit Card Release
Exam Start
Exam End
Answer Key
Result
Counselling
```

Each date should have a status such as:

* Official
* Tentative
* Expected
* Not Announced

The application should **never present an unannounced date as an official date**.

When official information is unavailable, the interface should clearly show:

> **Date Not Announced**

or:

> **Tentative Date**

# 🛠️ 35. Technology Stack

### Frontend

* React 19
* TypeScript
* Vite
* CSS
* Tailwind CSS
* Lucide React
* Motion

### Server

* Node.js
* Express
* TypeScript
* TSX

### AI

The current implementation includes an AI integration layer using the Google GenAI SDK and environment-based API configuration.

> If the AI provider is changed in a future version, the provider should remain behind the application's server-side AI service layer so the frontend does not need to expose API credentials.

### Data

The current prototype uses a server-side JSON data store for persistence.

For production deployment, this layer can be replaced with a dedicated database without changing the overall frontend architecture.

# 🚀 37. Run the Project

Clone or download the project.

Navigate into the project:

```bash
cd edu-carrier
```

Install dependencies:

```bash
npm install
```

Create the environment file:

```bash
.env.local
```

Add the required environment variables.

Then start the development server:

```bash
npm run dev
```

The application will be available through the local development URL displayed by the server.

---

# 🏗️ 38. Build for Production

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
